# FASDD_UAV 数据集说明

## 1. 来源与引用

本项目使用 **FASDD**（Flame and Smoke Detection Dataset）的无人机子集 `FASDD_UAV`。FASDD 由武汉大学 **Peng Yue 教授团队**构建，覆盖卫星、无人机与地面监控等多源火烟图像。

- 论文：Ming Wang, Peng Yue, Liangcun Jiang, Dayu Yu, Tianyu Tuo, Jian Li. *An open flame and smoke detection dataset for deep learning in remote sensing based fire detection*. Geo-spatial Information Science, 2025, 28(2): 511–526.
- 论文 DOI：[10.1080/10095020.2024.2347922](https://doi.org/10.1080/10095020.2024.2347922)
- 数据集 DOI：[10.57760/sciencedb.j00104.00103](https://doi.org/10.57760/sciencedb.j00104.00103)
- 项目页：[openrsgis/FASDD](https://github.com/openrsgis/FASDD)
- 数据许可：**CC BY-SA 4.0**（Science Data Bank 标注）

引用格式：

## 2. 归档不包含数据集

数据集体积约 14 GB，不随作品仓库分发。复现训练时请从上述官方渠道自行获取，并遵守 CC BY-SA 4.0 的署名与相同方式共享要求。

## 3. 数据集概况

| 项目 | 值 |
| --- | --- |
| 图像数量 | 25,097 张 `.jpg` |
| 标注格式 | COCO、VOC、TDML、YOLO（`annotations/` 下） |
| 类别 | `0 = fire`，`1 = smoke` |
| YOLO 切分 | train 12,551 / val 8,365 / test 4,181 |
| 标注目标 | 53,530 个（fire 36,308，smoke 17,222） |

## 4. 自行准备后的目录结构

将数据集放到 `数据集/FASDD_UAV/`，使目录结构为：

```
数据集/FASDD_UAV/
├── images/
├── annotations/
├── labels/            # 由脚本生成
├── train.txt          # 由脚本生成
├── val.txt
└── test.txt
```

## 5. 重建 YOLO 训练结构

在项目根目录执行：

```powershell
python 训练/脚本/prepare_false_positive_training.py    # 复制 labels/ 与 train/val/test；缺少负样本时跳过
python 训练/脚本/prepare_v31_print_demo_training.py    # 需要额外提供打印场景素材
python 训练/脚本/prepare_v32_print_demo_training.py    # 需要额外提供强化样本素材
python 训练/脚本/prepare_v32_hard_negative_training.py # 需要额外提供难负样本素材
```

脚本会自动：

- 从 `annotations/YOLO_UAV/labels` 复制 25,097 个标签到 `数据集/FASDD_UAV/labels`；
- 复制 `train.txt` / `val.txt` / `test.txt`；
- 从 `训练/素材/` 读取错误样本与强化样本，生成派生目录；
- 输出 5 个 YAML 到 `训练/配置/`，其中 `path:` 为相对路径 `../../数据集/FASDD_UAV`。

> `训练/素材/` 未包含在归档中。`prepare_false_positive_training.py` 在缺少该目录时会打印警告并跳过负样本，仍可完成基础 `labels/` 与切分文件重建；v31/v32 脚本需要自行补充素材后才能运行。

## 6. 训练配置

| YAML | 训练列表 | 用途 |
| --- | --- | --- |
| `fasdd_uav.yaml` | `train.txt` | 基线 |
| `fasdd_uav_fp.yaml` | `train_fp.txt` | 误报抑制 |
| `fasdd_uav_v31_print_demo.yaml` | `train_v31_print_demo.txt` | 打印场景增强 |
| `fasdd_uav_v32_print_demo.yaml` | `train_v32_print_demo.txt` | 强化样本 |
| `fasdd_uav_v32_print_demo_hardneg.yaml` | `train_v32_print_demo_hardneg.txt` | 难负样本（v4 来源） |

示例：

```powershell
python -c "from ultralytics import YOLO; YOLO('yolov8n.pt').train(data='训练/配置/fasdd_uav_fp.yaml', epochs=20, imgsz=640, batch=16)"
```
