# 林焰智巡森林火灾/烟雾检测模型报告

## 1. 模型版本

模型名称：Real Scene v3 - No Print/Phone False Positive

模型文件：

- `models/real_scene_v3_no_print_phone_fp/best.pt`

该模型是当前项目中效果较好的真实场景稳定版模型。它的核心特点是：对真实火焰、烟雾保持检测能力，同时明显降低打印照片、手机屏幕照片、普通无火无烟画面造成的误报。

## 2. 模型定位

本模型面向真实巡检场景使用，而不是面向“打印图片展示识别”的评委演示场景。

当前模型可以做到：

- 将打印出来的火焰/烟雾照片放在摄像头前时，不轻易触发报警。
- 将手机屏幕上的火焰/烟雾照片放在摄像头前时，不轻易触发报警。
- 对普通无火无烟画面保持较低误报。

这个行为更符合真实部署逻辑：系统应该识别真实环境中的火焰和烟雾，而不是把二次成像的照片、屏幕内容当成真实火情。

但如果比赛现场需要向评委展示“打印照片也能被识别”，则不建议使用本模型作为展示模型。该场景应单独准备一个更敏感的展示模型，或临时切换到旧版模型。

## 3. 训练基础

基础模型：

- `runs/detect/runs/fasdd_uav_yolov8n_finetune_v2/weights/best.pt`

训练数据：

- 原始 FASDD-UAV 数据集
- 新增误报负样本：`新的错误样本`
- 新增负样本数量：269 张去重图片
- 新增负样本标签：全部为空标签，即无 `fire`、无 `smoke`

训练目标：

- 降低烟雾类误报
- 降低打印照片/手机照片导致的非真实场景误报
- 保持火焰、烟雾真实目标检测能力

## 4. 类别定义

| 类别 ID | 类别名称 | 含义 |
| --- | --- | --- |
| 0 | fire | 火焰 |
| 1 | smoke | 烟雾 |

默认输入尺寸：640 x 640

默认置信度阈值：0.25

## 5. 验证集指标

| 指标 | 数值 |
| --- | ---: |
| Precision | 0.89057 |
| Recall | 0.85927 |
| mAP50 | 0.91862 |
| mAP50-95 | 0.67659 |

整体来看，模型在保持较高 mAP50 的同时，精度和召回保持在可接受范围内。

## 6. 误报抑制效果

使用 269 张近期误报样本进行测试，默认置信度阈值为 0.25。

| 模型版本 | 误报图片数 | 误报率 |
| --- | ---: | ---: |
| full 原始模型 | 142 / 269 | 52.79% |
| finetune_v2 | 102 / 269 | 37.92% |
| Real Scene v3 | 2 / 269 | 0.74% |

结果说明：

- 原始模型在该批误报样本上误报较多。
- finetune_v2 有一定改善，但仍存在明显误报。
- Real Scene v3 将误报率降低到 0.74%，对当前收集到的误报场景有明显抑制效果。

## 7. 无火无烟样本检查

以下两张样本已确认属于训练集中的负样本，标签文件为空，并且当前模型检测结果为 0 个目标框：

- `neitherFireNorSmoke_UAV000741.jpg`
- `neitherFireNorSmoke_UAV000922.jpg`

这两张图片可用于展示“无火灾、无烟雾时系统不误报”的效果。

## 8. 使用建议

推荐使用本模型的场景：

- 真实摄像头巡检
- 室外/室内真实环境中的火焰、烟雾检测
- 展示系统对无火无烟场景不误报
- 展示系统不会被打印照片、手机照片轻易触发

不推荐使用本模型的场景：

- 需要拿打印火焰照片给评委展示识别
- 需要拿手机屏幕火焰照片给评委展示识别
- 需要刻意证明模型能识别二次成像图片

如果后续评委展示必须识别打印图片，建议单独准备一个展示模型，并在演示时明确切换模型版本，避免影响真实场景模型的部署效果。

## 9. 结论

Real Scene v3 是当前项目中更适合真实部署的模型版本。它显著降低了近期误报样本中的错误报警，尤其适合用于真实场景巡检和无火无烟稳定性展示。

该模型不应被视为打印照片展示模型。它的价值在于更接近真实火灾巡检系统的行为：只对真实场景中的火焰和烟雾保持敏感，对打印照片、手机屏幕照片等非真实火情输入保持克制。
