# 林焰智巡模型性能说明文档

## 1. 文档目的

本文用于说明林焰智巡火焰/烟雾检测模型的性能评价口径，包括检测任务定义、核心指标含义、补充测试统计、推理性能和性能结论。本文重点阐述模型能力本身，不展开系统功能、演示流程或业务场景。

## 2. 检测任务定义

模型任务为火焰与烟雾目标检测。模型输入为图像帧，输出为目标类别、置信度和检测框位置。

类别定义如下：

| 类别 ID | 类别名称 | 含义 |
| --- | --- | --- |
| 0 | fire | 火焰 |
| 1 | smoke | 烟雾 |

默认输入尺度为 640，默认置信度阈值为 0.25。

## 3. 核心评价指标

### Precision

Precision 表示模型输出的检测结果中，真实有效目标所占比例。该指标主要用于衡量误报控制能力。Precision 越高，说明模型将非目标误判为火焰或烟雾的比例越低。

### Recall

Recall 表示真实存在的目标中，被模型成功检出的比例。该指标主要用于衡量漏检控制能力。Recall 越高，说明模型漏掉真实火焰或烟雾目标的比例越低。

### mAP50

mAP50 是在 IoU=0.50 条件下计算的平均精度，用于衡量模型在目标分类和目标定位上的综合表现。该指标是目标检测任务中常用的整体性能指标。

### mAP50-95

mAP50-95 是在多个 IoU 阈值下计算的平均精度，评价标准比 mAP50 更严格。该指标更能反映模型检测框定位质量和复杂条件下的稳定性。

## 4. 当前模型指标

当前模型版本为 `v4.0_for_preview`。

验证集指标如下：

| 指标 | 数值 |
| --- | ---: |
| Precision | 0.882 |
| Recall | 0.864 |
| mAP50 | 0.918 |
| mAP50-95 | 0.669 |

从结果看，模型 mAP50 达到 0.918，说明在 IoU=0.50 的常规评价条件下具有较高检测精度。Precision 为 0.882，说明误报控制较好。Recall 为 0.864，说明真实目标检出能力较稳定。mAP50-95 为 0.669，说明在更严格定位标准下仍具备可用精度，但检测框精细定位仍有继续提升空间。

## 5. 补充测试统计

除验证集指标外，项目还对模型进行了补充样本测试，用于观察模型对新增正样本、负样本和历史误报样本的表现。

| 测试项 | 结果 |
| --- | ---: |
| 新增正样本检出 | 25 / 25 |
| 新增负样本误报 | 0 / 12 |
| 前序正样本检出 | 4 / 4 |
| 前序负样本误报 | 0 / 4 |
| 旧误报样本池误报 | 2 / 322 |

根据上述统计，旧误报样本池误报率为 0.62%。该结果说明模型对已收集干扰样本具有较好的误报抑制效果。

## 6. 推理性能

v4.0_for_preview 已导出 PyTorch、ONNX 和 RKNN 格式。其中 FP RKNN 版本可用于 RK3588 NPU 推理。

样例级应用推理速度约为 42ms/帧。测试输入为 1280x720 图像，经缩放和 letterbox 预处理后进入 640 尺度模型。

该推理速度可作为端侧模型运行效率参考。实际运行速度会受到输入分辨率、预处理方式、后处理实现和硬件负载影响。

## 7. 量化状态

模型已生成 INT8 RKNN 版本，但在当前运行环境中曾出现类别分数异常，因此暂不作为稳定性能结论的主要依据。

当前性能结论以 PyTorch 验证指标和 FP RKNN 推理统计为主。

## 8. 性能结论

v4.0_for_preview 在验证集上取得 Precision 0.882、Recall 0.864、mAP50 0.918、mAP50-95 0.669。整体上，模型具备较好的火焰与烟雾检测能力，误报控制和目标检出能力较为均衡。

从补充测试看，模型对新增正样本保持稳定检出，对新增负样本和历史误报样本具有较低误报。端侧 FP RKNN 推理速度约为 42ms/帧，具备实时检测所需的基础推理性能。

后续优化重点包括：提升 mAP50-95，改善检测框精细定位；扩大负样本覆盖范围，进一步降低误报；继续验证 INT8 量化链路，在保持精度的前提下提升推理速度。
