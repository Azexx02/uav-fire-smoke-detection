# 林焰智巡项目答辩稿

尊敬的各位评委老师：

本项目名称为“林焰智巡”，是一套面向火焰与烟雾目标检测的智能巡检系统。项目围绕火灾早期识别、检测结果留存、专家评审和样本闭环管理展开，目标是在摄像头实时采集场景下，对画面中的火焰和烟雾进行自动检测，并为后续复核和模型优化提供完整的数据支撑。

项目背景来自火灾巡检中的两个现实问题。第一，火焰和烟雾在早期阶段可能持续时间短、范围小，单纯依赖人工观察容易出现漏检。第二，火灾预警系统对误报较为敏感，如果系统频繁将灯光、反光、红色物体等非火灾目标判断为火情，会降低系统可信度。因此，本项目在模型训练和系统设计中同时关注识别能力、误报控制和结果可追溯性。

系统主要由五个模块构成：实时检测、历史回看、专家评审、模型报告和素材管理。实时检测模块负责接入摄像头画面并完成火焰、烟雾检测；历史回看模块用于保存检测图片、三连拍记录和告警视频；专家评审模块支持对检测记录进行人工判定并统计实测准确度；模型报告模块展示当前模型的关键指标；素材管理模块用于整理误报、漏报和强化训练材料，服务于后续模型迭代。

算法部分采用 YOLOv8 目标检测框架。模型类别包括两类：类别 0 为 fire，表示火焰；类别 1 为 smoke，表示烟雾。训练过程中，项目以公开火灾烟雾数据为基础，并结合现场采集样本、困难负样本和误报样本进行多轮微调。相比只完成一次训练，本项目更强调“测试、评审、整理样本、继续训练”的迭代过程。

当前用于展示的模型版本为 `v4.0_for_preview`。该版本的验证集指标为：Precision 0.882，Recall 0.864，mAP50 0.918，mAP50-95 0.669。从指标看，模型在目标检测任务上具有较高的整体精度，精确率与召回率保持相对均衡。专项测试中，模型在新增正样本上实现 25/25 检出，在新增负样本上 0/12 误报；旧误报样本池中 2/322 出现误报。上述结果表明，该版本在保持识别能力的同时，对已收集的干扰样本具有较好的抑制效果。

工程实现方面，系统后端提供检测、摄像头、历史记录、专家评审和报告接口；前端提供实时演示、历史回看、专家评审、模型报告和素材管理页面。为降低实时画面延迟，摄像头线程持续读取最新帧，模型按设定间隔进行推理，其余画面复用最近一次检测结果，从而降低逐帧推理带来的画面滞后。项目已部署到 RK3588 开发板，并配置了开机自启动，能够满足现场演示的稳定运行要求。

本项目的主要特点有三点。第一，系统覆盖了从实时检测到结果复核的完整流程，而不是单一图片检测程序。第二，模型训练过程引入了误报样本和负样本强化，能够针对实际测试中发现的问题进行迭代优化。第三，系统保留了专家评审和素材归档功能，使检测结果能够转化为后续训练数据，形成可持续改进的数据闭环。

项目仍存在进一步优化空间。后续可以补充夜间、逆光、雨雾、小目标火点等复杂环境样本；继续扩大负样本覆盖范围；进一步验证不同量化模型在 RK3588 上的稳定性和速度表现；并完善专家评审结果到训练集构建的自动化流程。

综上，林焰智巡完成了火焰与烟雾检测模型、实时摄像头识别、历史记录、专家评审和素材管理等核心功能。当前模型在验证指标和专项测试中表现稳定，系统具备较完整的工程演示能力和后续扩展基础。我的汇报完毕，谢谢各位评委老师。
