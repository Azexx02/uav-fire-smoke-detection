# v4.0_for_preview 模型性能报告

## 1. 模型概况

模型名称：`v4.0_for_preview`

任务类型：火焰与烟雾目标检测

模型框架：YOLOv8

类别定义：

| 类别 ID | 类别名称 | 含义 |
| --- | --- | --- |
| 0 | fire | 火焰 |
| 1 | smoke | 烟雾 |

默认输入尺度：640

默认置信度阈值：0.25

主要模型文件：

| 文件 | 说明 |
| --- | --- |
| `models/v4.0_for_preview/best.pt` | PyTorch 权重 |
| `models/v4.0_for_preview/best.onnx` | ONNX 导出模型 |
| `models/v4.0_for_preview/v4.0_for_preview_fp_rk3588.rknn` | RK3588 FP RKNN 模型 |
| `models/v4.0_for_preview/v4.0_for_preview_int8_rk3588.rknn` | RK3588 INT8 RKNN 模型 |

## 2. 验证集检测指标

| 指标 | 数值 |
| --- | ---: |
| Precision | 0.882 |
| Recall | 0.864 |
| mAP50 | 0.918 |
| mAP50-95 | 0.669 |

## 3. 指标解释

Precision 为 0.882，表示模型输出的检测结果中，真实有效目标占比较高。该指标主要反映误报控制能力。

Recall 为 0.864，表示验证集中真实存在的火焰或烟雾目标大部分能够被检出。该指标主要反映漏检控制能力。

mAP50 为 0.918，表示在 IoU=0.50 的评价条件下，模型具有较高的综合检测精度。

mAP50-95 为 0.669，表示在更严格的多 IoU 阈值评价条件下，模型仍保持可用的检测框定位能力。

综合来看，v4.0_for_preview 在精确率、召回率和定位精度之间保持了较平衡的性能表现。mAP50 高于 0.9，说明模型在常规目标检测评价条件下具有较强的识别能力；mAP50-95 相比 mAP50 有所下降，说明在更严格定位标准下，检测框精细定位仍有进一步优化空间。

## 4. 补充测试统计

| 测试项 | 结果 |
| --- | ---: |
| 新增正样本检出 | 25 / 25 |
| 新增负样本误报 | 0 / 12 |
| 前序正样本检出 | 4 / 4 |
| 前序负样本误报 | 0 / 4 |
| 旧误报样本池误报 | 2 / 322 |

补充测试结果显示，模型对已收集正样本保持稳定检出，对已收集负样本和历史误报样本具有较好的误报抑制效果。旧误报样本池误报率为 0.62%。

## 5. 推理性能

RK3588 FP RKNN 版本样例级应用推理速度约为 42ms/帧。测试输入为 1280x720 图像，经缩放和 letterbox 预处理后进入 640 尺度模型。

该速度统计包含模型输入预处理、模型推理及基础输出处理开销，可作为端侧模型运行效率参考。实际速度会受到输入分辨率、预处理方式、后处理实现和硬件负载影响。

## 6. 模型格式与量化状态

v4.0_for_preview 已完成 PyTorch、ONNX 和 RKNN 格式导出。

FP RKNN 模型可用于 RK3588 NPU 推理。INT8 RKNN 模型已生成，但在当前运行环境中曾出现类别分数异常，因此不作为稳定性能结论的主要依据。

当前性能报告中的检测指标来自最终模型验证结果；推理速度采用 FP RKNN 版本的样例级应用推理统计。

## 7. 性能结论

v4.0_for_preview 的验证集 mAP50 为 0.918，Precision 为 0.882，Recall 为 0.864，说明模型具备较好的火焰与烟雾检测性能。补充测试中，模型在正样本检出和负样本误报控制方面表现稳定。端侧 FP RKNN 推理速度约为 42ms/帧，具备在 RK3588 平台进行实时检测的基础性能。

模型后续优化重点包括：继续提升 mAP50-95，改善严格定位条件下的检测框质量；扩大负样本覆盖范围，进一步降低误报；继续验证 INT8 量化链路，争取在保持精度的同时提升推理速度。
